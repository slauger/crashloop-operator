# config/

Generated manifests and examples. This is **not** a kustomize tree, and there is
deliberately no `kustomization.yaml` or `PROJECT` file: the Helm chart in
[../charts/crashloop-operator](../charts/crashloop-operator) is the only
supported install path, so a second, parallel set of deployment manifests would
only drift out of step with it.

| Path | Generated by | Consumed by |
|---|---|---|
| `crd/bases/` | `make manifests` | The chart copies it into `charts/crashloop-operator/crds/`, and `make uninstall` deletes from it. Also the CRD path envtest loads in the API tests. |
| `rbac/role.yaml` | `make manifests` | `make check-rbac`, which fails if the chart grants more or less than the `+kubebuilder:rbac` markers declare. Not applied directly. |
| `samples/` | Hand-written | Documentation. Keep it in step with the CRD fields. |

Nothing here is edited by hand except `samples/`. Run `make manifests` after
changing an API type or an RBAC marker; `make check-manifests` fails if you
forget.
