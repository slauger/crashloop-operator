{{ include "crashloop-operator.fullname" . }} has been installed in namespace {{ .Release.Namespace }}.

The operator does nothing until a CrashLoopPolicy exists. CrashLoopPolicy is
cluster-scoped, so it is created without a namespace:

  kubectl apply -f - <<'POLICY'
  apiVersion: crashloop-operator.lauger.de/v1alpha1
  kind: CrashLoopPolicy
  metadata:
    name: default
  spec:
    dryRun: true
  POLICY

Start with dryRun: true. The operator will log and emit events for the
workloads it would scale down without touching them. Set it to false once the
output looks right.

Check what the policy is doing:

  kubectl get clp
  kubectl describe clp default
